## Arithmetic

- [Basic](#basic-arithmetic)
- [Advanced](#advanced-arithmetic)
- [Unary Operations](#unary-operations)

### Basic Arithmetic

#### Addition

Usage: `num + num`
Symbol: `+`

Add values together.

#### Subtraction

Usage: `num - num`
Symbol: `-`

Subtract values from each other.

#### Multiplication

Usage: `num * num`
Symbol: `*`

Multpily values together.

#### Division

Usage: `num / num`
Symbol: `/`

Divide values by each other.

### Advanced Arithmetic

#### Modulo

Usage: `num % num`
Symbol: `%`

Used to calculate the remainder of an operation.

e.g. `5 % 5 = 0`

#### Integer Division

Usage: `num // num`
Symbol: `//`

Used to divide numbers by each other while discarding any decimals.

e.g. `5 // 4 = 1`

#### Raising to Powers

Usage: `num ^ num`
Symbol: `^`

Used to raise one number to another.

e.g. `5 ^ 3 = 125`

#### Roots

Usage: `num $ num`
Symbol: `$`

Used to find the root of a value.

### Unary Operations

#### Increment

Usage: `num++`
Symbol: `++`

Used to increment a value by 1.

#### Decrement

Usage: `num--`
Symbol: `--`

Used to decrement a value by 1.

#### Square

Usage: `num^^`
Symbol: `^^`

Used to square a value.

#### Square Root

Usage: `num$$`
Symbol: `$$`

Used to calculate the square root of a value.
